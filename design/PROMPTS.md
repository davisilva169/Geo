# Prompts das pranchas

Geradas com a ferramenta integrada de imagens (image_gen), sem CLI ou API externa configurada. Imagens destinadas exclusivamente à avaliação de identidade visual. Cada prompt corresponde a uma prancha de seis painéis. Nenhum asset oficial de bandeira foi produzido.

## 01 / PLAYFUL MINIMAL
+
Use case: ui-mockup.
Create an ORIGINAL polished visual direction presentation board for a Brazilian Portuguese geography flag learning WEB GAME, working name "Rumo". This is a static art direction proposal, not production software.
Output a large landscape image, ideally 3840x2560, crisp and legible. Flat front-facing digital UI screenshots, no photographic devices, no perspective, no desk. Board with a restrained header, then 3 columns x 2 rows of distinct well-separated panels with consistent margins. Five desktop interface panels and one mobile adaptation panel. Each panel must show a complete plausible implementable screen, not just isolated components. Elegant spacing, modern game personality, light theme, rounded cards, subtle shadows, accessible dark text.
Exact panel titles:
"01 · Início" — Rumo logo, welcome "O mundo começa com uma bandeira.", hero "Vamos explorar?", main button "Começar", small mode cards "Normal", "Avalanche", "Radar", "Continuar revisão", small progress "120 / 196".
"02 · Escolha seu modo" — three differentiated substantial mode cards "Normal" with "Aprenda no seu ritmo", "Avalanche" with "Acerte antes de cair", "Radar" with "Encontre a bandeira". Buttons "Jogar".
"03 · Flashcards" — normal learning screen with progress "12 / 20", pause icon, a large Japan flag (exact flat white rectangular field with centered red circle, no waving), prompt "Qual é o país?", input "Digite o nome do país", primary "Confirmar", secondary "Revelar". Flag is hero with abundant breathing room.
"04 · Avalanche" — real falling flag playfield, three independent crisp rectangular flags at different heights: Japan, France, Germany, no country names or answer labels. Clear "2.450" score, "Combo ×5", three heart lives, subtle floor, pause, three compact powers with shortcut badges 1 2 3 below the field, permanently visible input "Digite um país". No distractions behind flags.
"05 · Resultados" — title "Cada rodada, mais mundo.", large "80%", "16 acertos", "4 erros", "02:40", prominent CTA "Revisar 4 erros", small clearly labeled evolution chart, recent history with "Sessão completa" versus "Revisão".
"06 · No celular" — a single portrait Avalanche screen with visible simulated virtual keyboard beneath the answer input, playfield above, score, hearts, touch power buttons. Mobile layout must be convincingly usable.
Use the same brand, typography and visual system across all six panels. Top-level board title specified below, a tiny palette strip with six swatches and hex labels in header. Footer "ESTUDO VISUAL · DADOS ILUSTRATIVOS · BANDEIRAS NÃO SÃO ASSETS FINAIS". Preserve recognizable flat flags; these are solely mockup illustrations. No fake photo or external brands, no corporate admin sidebar, no overly dense tiny text.
Board title: 01 / PLAYFUL MINIMAL
Art direction: joyful refined minimalism; off-white #F7F9FC canvas, white cards, cobalt #3157D5 primary, coral #F07867 ornamental, pale lemon #F4CD58 accent, dark #18243D type, green #17725B semantic success. Use modern rounded geometric sans typography resembling Plus Jakarta Sans for titles and DM Sans for body. Big generous headings, 20px rounded corners, playful bold two-tone simple globe and compass shapes, rounded line icons, tactile but restrained buttons. Hero includes a simple colorful globe and orbit. Optional tiny compass mascot only in home/results, not playfield. This should look sophisticated and joyful, not childish or corporate.
